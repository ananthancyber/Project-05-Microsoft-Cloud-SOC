# Day 06 — Repeated Authentication Failures: Validation Report

## 1. Validation Overview

| Field | Details |
|---|---|
| Project | Project 05 — Microsoft Cloud SOC |
| Detection ID | P05-D06-DET-001 |
| Detection | Repeated Authentication Failures |
| Data source | Microsoft Entra ID |
| Table | `SigninLogs` |
| Validation method | Real telemetry baseline and synthetic KQL test |
| Threshold | At least 3 failures in 15 minutes for the same user and IP |
| Status | Synthetic threshold validation passed |

## 2. Real Telemetry Baseline

The authentication baseline query returned:

| Metric | Observed result |
|---|---:|
| Total sign-in records | 38 |
| Successful sign-ins | 35 |
| Failed sign-ins | 3 |
| Unique users | 1 |
| Unique source IP addresses | 5 |

The brute-force detection query returned no groups meeting the configured threshold.

### Result

**Outcome:** No matching detection groups were found in the observed seven-day real Entra ID telemetry.

This result does not prove that no attack occurred. It means that the queried events did not satisfy the detection criteria.

## 3. Synthetic Detection Test

A KQL `datatable()` generated four synthetic failed sign-in records.

| Test attribute | Value |
|---|---|
| Synthetic user | `testuser@lab.local` |
| Synthetic IP | `192.0.2.10` |
| Synthetic failure code | `50126` |
| Number of events | 4 |
| First event | 10:00 UTC |
| Last event | 10:06 UTC |
| Detection threshold | At least 3 failures in 15 minutes |
| Expected outcome | One matching group |
| Observed outcome | One matching group containing 4 events |
| Test status | PASS |

### Result

**Outcome:** The KQL grouping and threshold logic behaved as expected with synthetic data.

The synthetic events were created inside the query. They were not generated by Entra ID, the P05 Windows endpoint, or a real attack.

## 5. Validation Conclusions

- The authentication baseline query executed successfully.
- Three failed sign-in records were observed in the seven-day baseline.
- No real-telemetry group met the configured three-failures-in-15-minutes threshold.
- The synthetic test returned one matching group containing four events.
- The KQL threshold logic passed the synthetic test.
- A real brute-force attack has not been demonstrated.
- Generation of a native Microsoft Sentinel analytics alert has not been validated by this test.
