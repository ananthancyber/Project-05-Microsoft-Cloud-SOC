# Day 13 — SOC Automation Validation

**Project:** Project 05 — Microsoft Cloud SOC, EDR & Threat Hunting Lab
**Platform:** Microsoft Sentinel and Microsoft Defender
**Environment:** `law-project05-soc`
**Validation focus:** Analytics-driven incident generation, automation-rule execution, and case-tag verification
**Evidence directory:** `screenshots/Day13/`

---

## 1. Validation Objective

The objective of this validation was to verify the behavior of the Day 13 SOC automation workflow.

The validation examined the following components:

1. Authentication-related analytics detection.
2. Security incident generation.
3. Automation rule activation.
4. Automated case-tagging execution.
5. Execution history for individual cases.
6. Visual verification of the `P05-SOC-Lab` tag.
7. Configuration of the authentication-investigation task.

The validation uses the Microsoft security portal's visible configuration, case records, and automation execution history.

## 12. Final Validation Summary

The Day 13 validation captured evidence of authentication incident generation, active automation-rule configuration, successful automation executions, and the presence of the lab tag on displayed cases.

The automation run history recorded successful execution of `P05 - Auto-Tag SOC Lab Cases` for case ID 196. The history for `P05 - Tag Invalid Credential Incidents` recorded successful executions for cases 195, 196, and 197.

These results demonstrate that the configured automation rules executed successfully for the displayed cases and that the intended lab tag was visible on incident records.

**Final result:** Detection and case-tagging automation validated for the displayed test cases, with configuration and execution evidence preserved in the Project 05 repository.
